# EduLens — запуск проекта

1. Распакуйте архив и откройте папку EduLens в VS Code.
2. Установите Node.js 24 LTS или более новую совместимую версию. В проекте используется встроенный node:sqlite.
3. Откройте терминал в папке EduLens и выполните:

```bash
npm run dev
```

4. Откройте http://localhost:4173
5. Выберите тестовый аккаунт ученика, учителя, директора или завуча.

Внешние npm-пакеты для запуска текущей версии не требуются.

## Проверка и сборка

```bash
npm test
npm run build
```

Сборка сервера: dist/server/index.js.

## Что включено

- web/: интерфейс, современные иконки, пошаговое обучение, аналитика и демоданные.
- worker/: серверный API.
- drizzle/: схема и миграции базы данных.
- scripts/: запуск, сборка и инструменты разработки.
- tests/: проверки связности данных и ограничений доступа.
- .openai/hosting.json: конфигурация исходного размещения Sites.

## Данные и размещение

Основной интерфейс работает в демонстрационном режиме. Все ученики, оценки, переписки и события вымышлены. Изменения сохраняются только в текущем браузере (localStorage). Выбор тестовой роли не является настоящей авторизацией.

Исходники серверного API включены, но копирование проекта не переносит облачную базу, загруженные файлы, секреты и настройки авторизации платформы. Для отдельного размещения серверной части нужно настроить Cloudflare Worker, D1 (DB), R2 (BUCKET) и авторизацию. Один GitHub Pages не запускает этот сервер.

## Загрузка в GitHub

Распакуйте архив. В репозитории нажмите Add file → Upload files и загрузите содержимое папки EduLens, затем сохраните изменения. Либо используйте Git из VS Code. Сам ZIP достаточно хранить только если вы хотите распространять архив, а не редактировать код в репозитории.

В архив не включены история Git, локальная база, переменные окружения, токены и временные файлы.
